SFTP connection limit

Storage providers cap how many connections one account may hold open (a Hetzner Storage Box allows 10). Every backup, check, restore, maintenance run and repository measuring holds one connection to its SFTP host while it works, and further ones wait their turn instead of failing. Now: {{.SFTPCap.Describe}}.

Add a repository

The chosen agent creates the repository (or connects to one already at that location) and becomes its first assigned agent. Choosing the server is for storage only the server can reach: the server creates it with its own engine, maintains it, and no agent is assigned until you assign one under Manage (which makes that agent open it first); an SFTP key path is then a path inside the server container, and a filesystem repository needs its path on the server. The SFTP path and S3 prefix start as <hostname>-<first 6 characters of the agent ID>-backup, readable and still unique to that agent, so unrelated data never shares a directory; change it if you want a different layout. Only the fields for the selected kind are used.
